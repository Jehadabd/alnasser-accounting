# خادم تذكير الديون عبر واتساب — برنامج الناصر

خادم صغير يرتبط برقم واتساب المحل كـ«جهاز مرتبط»، ويرسل رسائل التذكير التي يطلبها البرنامج فقط.

- **لا يقرأ الرسائل ولا يحفظها.** يرسل فقط.
- **يعمل على هذه الحاسبة فقط**، على `127.0.0.1:8765`: لا يصل إليه أحد من الشبكة.
- **جلسة الربط مشفّرة**، ولا تُفتح إلا بمفتاح الخادم المحفوظ في التخزين الآمن للبرنامج.

> ⚠️ هذه ليست طريقة رسمية من واتساب. الإرسال الآلي قد يعرّض الرقم للتقييد، وخصوصاً مع الإرسال الكثير أو التبليغ عن الرسائل.

## التشغيل
لا شيء يدوي. من البرنامج: الإعدادات ← تذكير الديون عبر واتساب ← خادم واتساب ← «تشغيل على هذه الحاسبة بضغطة». البرنامج:
1. يستعمل Git المثبّت إن وُجد، وإلا ينزّل MinGit. وينزّل Node.js المحمول. يطابق بصمة كل ملف (SHA-256) مع المصدر الرسمي.
2. يثبّت الخادم داخل مجلد بيانات البرنامج (`wa_local`)، بلا صلاحيات مدير.
3. يشغّل الخادم بلا نافذة. الخادم يتوقف وحده عند إغلاق البرنامج.

«متى يبدأ الخادم؟»: **مع فتح البرنامج** (الافتراضي)، أو **عند الحاجة فقط**.

## المتغيرات (يضعها البرنامج)
`API_KEY` • `PORT` • `HOST` • `STATE_DIR` • `LOG_FILE` • `PARENT_PID` (يتوقف الخادم إذا أُغلق البرنامج) • `MAX_PER_HOUR` (60)
