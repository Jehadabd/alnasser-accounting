# 📖 دليل نظام الاختبار الذكي (AF-QA Engine)

> **نظام اختبار آلي ذكي** يحاكي مستخدم بشري (محاسب + كاشير + مدقق حسابات)
> لاختبار نظام الديون والفواتير بشكل شامل.

---

## 🎯 الهدف

اختبار التطبيق بطريقة **ذكية وواقعية** للتأكد من:
- ✅ صحة حسابات الديون
- ✅ صحة تعديلات الفواتير
- ✅ تسلسل المعاملات
- ✅ عدم وجود تكرار أو فقدان بيانات
