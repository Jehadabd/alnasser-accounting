# Autonomous Financial QA Engine (AF-QA)

نظام اختبار ذاتي لتطبيق Shop Manager، مصمم ليعمل كـ "محرك حقيقة" (Truth Engine) للتحقق من الدقة المالية بنسبة 100%.

## 📂 المجلدات
*   `truth_engine/`: يحتوي على القواعد المالية (Rules) ونماذج البيانات (Models) التي تحاكي منطق التطبيق.
*   `automation/`: سكربتات التحكم في التطبيق (فتح، ضغط أزرار) باستخدام `pywinauto`.
*   `docs/`: شروحات تفصيلية للمنطق (اقرأ `EXPLANATION.md` أولاً).

## 🚀 التشغيل
1. تأكد من تثبيت Python.
2. ثبت المكتبات المطلوبة:
   ```bash
   pip install pywinauto pyyaml
   ```
3. عدّل ملف `config.yaml` ليطابق مسار التطبيق لديك.
4. (قريباً) شغّل ملف الاختبار الرئيسي.

## ⚠️ ملاحظة هامة
هذا المشروع مصمم ليكون **مراقباً خارجياً** للتطبيق. هو لا يتدخل في كود Flutter، بل يختبر التطبيق النهائي (`.exe`) كما يختبره المستخدم البشري، لكن بدقة الآلة.
